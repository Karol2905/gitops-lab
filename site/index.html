La arquitectura del laboratorio

GitHub guarda el código y ejecuta los pipelines. Google Cloud guarda el estado, la identidad y los dos entornos. Entre ambos no hay contraseñas: hay un token que dura minutos.

Cuatro ideas que sostienen el laboratorio

Si entiende estas cuatro, entiende por qué el flujo es seguro y repetible.

Sin secretos
GitHub entrega un token de pocos minutos. Google Cloud lo acepta solo si el repositorio, la rama o el entorno coinciden con un subject vinculado a la cuenta de servicio.
Estado compartido
Terraform anota lo que creó en un bucket de Cloud Storage, con bloqueo y versiones. Así dos ejecuciones nunca se pisan.
Aprobación humana
El entorno prod espera. Hasta que alguien aprueba, el job ni siquiera recibe un token para tocar Google Cloud.
Detección de deriva
Si alguien cambia algo en la consola, un plan programado lo detecta y abre un issue con la diferencia.

Qué hay detrás de esta dirección

Un sitio estático en Google Cloud no necesita servidor: un archivo HTML en un bucket con lectura pública.
